# Race Shop Inventory

Inventory app for the race team: count parts fast, QR labels on bins, stock by location (Shop, Hauler), user logins with View only / Editor / Master admin levels.

- **App:** https://hititautosport.github.io/race-inventory/
- **Code:** `index.html` (single file). Data lives in Supabase and is protected by sign-in and row level security; the key in the code is the public "publishable" key.
- **Build guide:** [BUILD_GUIDE.md](BUILD_GUIDE.md) — architecture, rules, database schema and roadmap.
